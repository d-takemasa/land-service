# ランドサービス株式会社 — Webサイト実装

ランドサービス株式会社のワイヤーフレームを実装した静的サイトです。プレーンな HTML / CSS / JS のみで構成されており、ビルド不要でそのまま公開できます。

## ページ構成

- `index.html` — トップページ（雑誌型レイアウト）
- `company.html` — 会社案内
- `kaitai.html` — 解体・遺品整理事業
- `fudousan.html` — 不動産事業
- `olive.html` — 植物販売事業
- `garage.html` — ガレージシェルター卸売事業
- `rental-space.html` — レンタルスペース事業
- `blog.html` — お知らせ・ブログ一覧
- `contact.html` — お問い合わせ

## ローカルで確認する

```bash
python -m http.server 8000
```

`http://localhost:8000` を開いてください。
